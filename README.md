# My Full Stack Project

Activity 17: a responsive webpage titled **My Full Stack Project**, built with semantic HTML, an external stylesheet, Flexbox, fluid sizing and media queries. This is a static frontend demonstration; no backend or installation is required.

## Run

Open `index.html` in a browser, or run `python -m http.server 8000` from this directory and visit `http://localhost:8000`.

## Files

- `index.html`: semantic page structure and accessible navigation.
- `styles.css`: external stylesheet, Flexbox layout and responsive rules.
- `evidence/`: Git history and validation evidence for submission.

## Git workflow

The repository contains separate commits for the page structure and responsive styling. A further change is committed on `feature/project-details` and merged into `main` with a merge commit.

View the history with `git log --graph --oneline --all --decorate`.
